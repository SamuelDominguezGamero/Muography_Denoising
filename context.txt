=================================================================================
                        ARCHITECTURE & COMPONENTS
=================================================================================

1. DATA LOADING & PREPROCESSING
   - normalize_channels(): Z-score normalization per channel independently
     * Prevents noisy channels (1, 2) from dominating training
     * Applied on-the-fly during training, keeps original HDF5 intact
     * NEW: Supports only_use_channel_0 mode for faster training

   - create_augmented_h5(): 16x data expansion with transformation metadata
     * 4 rotations (0°, 90°, 180°, 270°) × 4 flip modes (none, vertical, horizontal, both)
     * Stores metadata in HDF5 as strings: "orig_idx={i}, rotation={rot*90}°, flip={flip_mode}"
     * Separate augmentation per split (training/validation/test) to avoid data leakage
     * Auto-generated filename with _augmented suffix in same directory as original

2. MODEL ARCHITECTURE
   - conv_block(): Conv2D → BatchNorm → ReLU, repeated
   - unet_dynamic(): Dynamic U-NET builder with skip connections
   - Configurable levels (N_LEVELS=4) and filters (N_FILTERS=32)

3. TRAINING & MODEL PERSISTENCE
   - train_unet(): Lazy batch loading strategy
     * Loads one batch → applies normalization in RAM → trains → deletes batch
     * apply_normalization=True enables per-channel z-score normalization
     * Reports loss and MSE for training and validation
   
   - save_model(): Saves model as .keras format with hyperparameters
     * Path: models/UNET2D_{channels_str}_bs{batch}_ep{epochs}_lr{lr}/
     * Hyperparameters stored as JSON (batch_size, epochs, lr, filters, levels, timestamp)
   
   - load_trained_model(): Loads pre-trained model from disk if exists

4. VISUALIZATIONS
   - visualize_predictions(): Input | Prediction | Ground Truth (3 columns)
   
   - visualize_normalized_channels(): Shows normalization effect before/after
     * If only_use_channel_0: shows 1 channel original + 1 normalized (2 cols)
     * Otherwise: shows all 3 channels original + 3 normalized (6 cols)
   
   - visualize_augmented_samples_with_metadata(): Shows augmented samples + transformations
     * Displays metadata for each sample (rotation, flip info)
   
   - visualize_augmented_data(): Shows rotations applied to samples

=================================================================================
                        KEY FEATURES & DECISIONS
=================================================================================

1. EFFICIENT BATCH LOADING
   - Loads one batch at a time from HDF5
   - Applies preprocessing (normalization) only in RAM
   - Deletes processed batch after training step
   - Advantage: Works with large datasets without memory overflow

2. DATA AUGMENTATION WITH METADATA
   - Creates 16x expanded dataset automatically
   - Each augmented sample has metadata tracking original index + transformations
   - Stored in HDF5 as string dataset: {split}/augmentation_metadata
   - Enables reproducible tracking of synthetic data

3. CHANNEL NOISE MITIGATION
   - Channel 0 (log_counts): Clean, useful for geometry reconstruction
   - Channels 1, 2: High noise, low signal-to-noise ratio
   - Per-channel normalization prevents noisy channels from dominating
   - NEW: only_use_channel_0 option for faster training with primary channel only

4. ENVIRONMENT AGNOSTIC
   - Automatically detects "local" or "cluster" environment
   - Adjusts file paths accordingly
   - Same code works in both environments

5. MODEL NAMING CONVENTION
   - Format: UNET2D_{channels}_{batch_size}_{epochs}_{learning_rate}
   - With channel_0 mode: UNET2D_1ch_channel0_bs{batch}_ep{epochs}_lr{lr}
   - With all channels: UNET2D_3ch_bs{batch}_ep{epochs}_lr{lr}
   - Hyperparameters saved alongside model for reproducibility

=================================================================================
                        DEBUGGING & TROUBLESHOOTING
=================================================================================

Common Issues & Solutions:

1. HDF5 File Not Found
   - Check: environment variable set correctly (local/cluster)
   - Check: H5_FILE path exists
   - Solution: Verify file path matches your data location

2. Model Not Saving
   - Check: models/ directory exists
   - Check: write permissions in UNET0_2D.py location
   - Solution: Create models/ folder manually if needed

3. Channel Mismatch
   - Check: only_use_channel_0 setting matches data dimensions
   - Check: Augmented HDF5 has correct channel count
   - Solution: If switching modes, regenerate augmented HDF5 with force_augmentation_rewrite=True

4. Memory Issues
   - Solution: Reduce BATCH_SIZE
   - Solution: Set only_use_channel_0=True for faster training
   - Note: Batch loading already manages memory efficiently

5. Visualization Not Showing
   - Check: visualization=True
   - Check: environment != "cluster" (plots not available on headless systems)
   - Solution: Set environment="local" if testing locally
