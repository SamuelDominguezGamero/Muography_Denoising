=================================================================================
                        4-CHANNEL ARCHITECTURE (UNET1_2D)
=================================================================================

UNET1_2D works with 4 input channels instead of 3:

INPUT SHAPE: (128, 128, 4)

Channel 0: log_counts
  ├─ Source: m_counts_2d from merge_results_1.py
  ├─ Meaning: Event density (how many muons passed through each cell)
  ├─ Useful for: Primary geometry reconstruction signal
  └─ Formula: log(N+1) to compress dynamic range and avoid log(0)

Channel 1: mean_theta_sq_z  
  ├─ Source: m_sum_theta_sq_2d / m_counts_2d from merge_results_1.py
  ├─ Meaning: Average of squared scattering angles
  ├─ Useful for: Material characterization (different materials scatter differently)
  └─ Formula: E[θ²] = (Σθ²) / N

Channel 2: var_poca_z
  ├─ Source: Variance of POCA Z-coordinates with Bessel correction
  ├─ Meaning: Spread of POCA points along Z-axis (depth dimension)
  ├─ Useful for: Thickness proxy (more spread = thicker material)
  └─ Formula: Var(Z) = E[Z²] - (E[Z])², sample var with Bessel correction

Channel 3: std_theta
  ├─ Source: Standard deviation of scattering angle θ
  ├─ Meaning: Variability in scattering behavior
  ├─ Useful for: Material discrimination (variance tells about material properties)
  └─ Formula: Std(θ) = √(E[θ²] - (E[θ])²)

GROUND TRUTH (OUTPUT):
  └─ Binary mask (128, 128, 1): which cells contain material (geometry)

1. 4-Channel Design Rationale (UNET1_2D)
   - Channel 0: Event counts (primary signal, most reliable)
   - Channel 1: Scattering angle (material characterization)
   - Channel 2: Z-variance (NEW - encodes depth/thickness information)
   - Channel 3: Scattering variance (NEW - material discrimination)
   - Advantage: More complete physical description than UNET0_2D

2. Z-Coordinate Statistics (Channel 2)
   - Captures variance of POCA point positions along Z-axis
   - Serves as proxy for material thickness
   - Cells with more spread-out POCA points → thicker materials
   - Critical for 3D geometry reconstruction accuracy

3. Scattering Variance (Channel 3)
   - Std(θ) captures variability in scattering angles
   - Different materials have different scattering signatures
   - Helps model distinguish materials at boundaries
   - Complements Channel 1 (average scattering)

4. Per-Channel Normalization (All 4 channels)
   - Z-score: (x - μ) / σ applied independently per channel
   - Prevents magnitude-based channel dominance
   - Essential because raw channel values have different scales
   - Keeps original HDF5 untouched (normalization during training)

5. Data Pipeline Integrity
   - POCA1.py → merge_results_1.py → create_h5_dataset.py → UNET1_2D.py
   - Each stage preserves data quality and structure
   - Metadata tracking enables debugging and reproducibility
   - Separation of concerns: data generation, aggregation, training

6. UNET0 vs UNET1 Backward Compatibility
   - UNET0_2D uses original POCA.py (3 matrices)
   - UNET1_2D uses new POCA1.py (5 matrices)
   - Files don't conflict (POCA.py ≠ POCA1.py)
   - Can run both pipelines independently
