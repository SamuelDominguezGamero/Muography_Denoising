=================================================================================
                            PIPELINE OVERVIEW
=================================================================================

Data Flow: Simulation → POCA1 (5 fields) → merge_results_1 (4 channels) 
           → create_h5_dataset1 (HDF5) → UNET1_2D (training)

LAYER 1: SIMULATION (loop_configuration_files1.py)
  • Creates geometry JSON files + boolean 2D masks (128×128)
  • Generates ground truth density = bool_mask × material_density
  • Materials: lead=11.35, iron=7.874, uranium=18.95 g/cm³
  • Submits SLURM jobs for Geant4 (n_muons_per_job=30k, total_muons=1.5M)
  • Runs makeHLTuple + POCA1 per seed
  • Submits merge job with --dependency=afterok

LAYER 2: POCA1.py (Per-seed POCA reconstruction)
  • Input: ROOT file with muon tracks
  • Output: 5 fields (128×128×1 each after 2D projection)
    1. counts_2d              2. sum_theta_2d           3. sum_theta_sq_2d
    4. sum_poca_z_2d          5. sum_poca_z_sq_2d
  • Storage optimization: 3D→2D in RAM (no disk intermediate)
    - 5 matrices (128×128×128) in RAM → project → save (128×128×1) × 5 = 80KB
    - Prevents I/O bottleneck with 100+ parallel jobs
    - Reduces storage from 64GB to 8MB

LAYER 3: merge_results_1.py (Accumulate + compute 4 channels)
  • Input: All POCA_*.npy files for one geometry
  • Output: 4-channel training tensor (128×128×4)
  
  Channels computed:
    Channel 0: log_counts = log(Σ counts + 1)
    Channel 1: mean_theta_sq_z = (Σ θ²) / (Σ N)
    Channel 2: var_poca_z = E[Z²] - (E[Z])² + Bessel correction
    Channel 3: std_theta = √(E[θ²] - (E[θ])²)
  
  • Output file: MERGED_<geom>_Muons_<count>_2D.npy
  • Output dict: {"training_channels": (128, 128, 4), metadata}

LAYER 4: create_h5_dataset1.py (HDF5 creation)
  • Input: MERGED_*_2D.npy (4-channel) + ground_truth_density2D.npy
  • Processing:
    1. Load 4-channel from 'training_channels' key
    2. Match geometries between MERGED and GT files
    3. Create train/val/test splits (70/15/15)
    4. Write with chunking (enables future appending)
  
  • Output: 128x128x4.h5
    /training/images (N, 128, 128, 4) | labels (N, 128, 128, 1)
    /validation/...  /test/...       (same structure)
    Per-sample metadata: n_muons_total, material, word, geometry params
    Attributes: n_muons_min/max/avg, has_mixed_muon_counts

LAYER 5: UNET1_2D.py (Training)
  • Input: 128x128x4.h5
  • Process:
    1. Load train/val/test splits
    2. Per-channel z-score normalization (independent)
    3. Data augmentation: 16x (4 rotations × 4 flips)
    4. Train 4-channel U-NET (BATCH_SIZE=16, EPOCHS=100, LR=1e-3)
    5. Validate on holdout set
    6. Visualize: predictions vs ground truth
    7. Save model + hyperparameters
  
  • Output: ./unet1_2d_models/UNET2D_4ch_bs16_ep100_lr0.001/
    - model.keras
    - hyperparameters.json


=================================================================================
                        4-CHANNEL ARCHITECTURE
=================================================================================

Input Shape: (128, 128, 4)

Channel 0: log_counts
  Purpose: Event density, PRIMARY geometry signal
  Formula: log(accumulated_counts + 1)
  Quality: EXCELLENT

Channel 1: mean_theta_sq_z
  Purpose: Average squared scattering angle (material characterization)
  Formula: (Σ θ²) / (Σ N)
  Quality: GOOD

Channel 2: var_poca_z [NEW for UNET1]
  Purpose: Z-spread → thickness/depth information
  Formula: E[Z²] - (E[Z])² with Bessel correction
  Quality: FAIR (high noise for thin regions)

Channel 3: std_theta [NEW for UNET1]
  Purpose: Scattering variance for material discrimination
  Formula: √(E[θ²] - (E[θ])²)
  Quality: GOOD

Output Shape: (128, 128, 1) - geometry+density mask (0-1)

=================================================================================
                        KEY DESIGN DECISIONS
=================================================================================

Storage Optimization (POCA1.py):
  ✓ 3D→2D projection in RAM without disk intermediate
  ✓ Reduces per-seed storage: 640 MB → 80 KB
  ✓ Enables 100+ parallel cluster jobs

Ground Truth Strategy:
  ✓ Pre-compute: bool_mask × material_density
  ✓ Store as float32 (64 KB per geometry)
  ✓ Load directly during training (no computation needed)

Data Augmentation:
  ✓ 16x expansion: 4 rotations × 4 flips
  ✓ Metadata tracking: original index + transformations
  ✓ Stored in separate HDF5 file with _augmented suffix

Per-Channel Normalization:
  ✓ Z-score (mean=0, std=1) applied independently per channel
  ✓ On-the-fly normalization (HDF5 unchanged)
  ✓ Prevents high-magnitude channels from dominating
